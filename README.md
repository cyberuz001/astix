# ASTIX — Cinematic 3D Fashion E-Commerce Experience

A production-quality, premium, long-scrolling, cinematic 3D fashion website for **ASTIX** — architectural footwear and technical storm shells engineered around human movement, material restraint, and contemporary visual culture.

## Key Features

- **Brand-First Cinematic Introduction**: The homepage opens with a 3D-sculpted ASTIX insignia and brand identity before revealing product silhouettes.
- **Continuous 3D Scroll Choreography**: Overlapping transitions between footwear and technical outerwear with unhurried pacing, depth-masking, and camera-like translation.
- **Audiowide Typography System**: Geometric headline architecture paired with neutral sans-serif body typography.
- **Auto-Hiding Navigation**: Smart top bar that smoothly disappears when scrolling down and reappears when scrolling up or returning to the top.
- **Dimensional Card Overflow**: E-commerce cards where product silhouettes break out 60–80px above card pedestals with realistic studio contact shadows.
- **Interactive Colorways**: Live 3D colorway switching across White, Obsidian, and Crimson Atelier editions.
- **Responsive Architecture**: Fluid scaling across desktop, tablet, and mobile displays.

## Tech Stack

- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **3D & Motion**: Three.js, Lenis Smooth Scroll
- **Icons**: Lucide React

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/cyberuz001/astix.git

# Navigate to project directory
cd astix

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
